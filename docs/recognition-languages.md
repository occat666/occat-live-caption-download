# 识别语言与实时翻译

“内容语言”决定如何听写音频；“翻译目标”决定译文使用哪一种语言；界面语言只改变软件菜单，三者分别设置。

## 选择字幕识别语言

| 选项 | 适用情况 |
| --- | --- |
| 中文（简体） | 使用中文识别，以简体显示中文原文。 |
| 中文（繁体） | 使用相同的中文识别，以繁体显示中文原文。 |
| 英文 | 正在播放英文内容，字幕显示英文原文。 |
| 日文 | 正在播放日文内容，字幕保留日文原文和日文汉字。 |
| 韩文 | 正在播放韩文内容，字幕显示韩文原文。 |
| 自动判断 | 每句按实际语音判断语言，适合不同语言交替出现的内容。很短的语音可能需要参考前面的片段；语言明确时可手动选择。 |

两个中文选项使用同一个中文识别能力，仅改变显示；在它们之间切换不重载识别模型，也不改变界面语言。模型支持中文时两项同时可用，不支持中文时两项同时禁用。原来的“中英混合”设置会迁移到“自动判断”。语种切换不重置字体、位置或背景设置。

## 字幕字形（中日韩）

“字幕外观”的中文字形选项统一为中文（简体）、中文（繁体），另有日语（日本字形）、韩语（韩文字形）和保留原文。原文简繁与译文目标分别生效，选择日/韩字形本身不执行翻译。译文按目标使用中日韩字形，原文设置不会改写日文或韩文译文。未收录的字符继续使用所选字幕字体补齐。

字形设置独立保存，切换后立即刷新当前字幕和预览；不修改界面语言、识别语种或翻译目标。日语、韩语字形并不把中文翻译成日语或韩语。两份原始字体按 SIL OFL 1.1 随附许可，字重沿用现有滑块；常规字幕字体列表仍保留原有四种字体和用户导入的字体。

语言选项取决于所选模型的实际能力：多语言 Whisper 支持上述语种；英语专用 Whisper、中文 Paraformer 等受模型能力限制。模型不支持的选项会禁用并显示说明，不能把不支持的语言强行交给模型。导入模型后也按该模型能力处理；若要识别日文或韩文，请使用兼容的多语言模型。

## 独立控制实时翻译

- 关闭“实时翻译”：只显示识别到的原文，不安排实时翻译任务。
- 打开“实时翻译”：目标可选中文（简体）、中文（繁体）、英文、日文、韩文，支持中、英、日、韩互译。中文简繁在本地转换，源语言和目标相同时直接显示，不重复运行模型。
- “同时显示原文”开启且设置为两行时，原文在上、目标译文在下；关闭时，译文准备好后只显示译文。
- 翻译在后台执行：原文先显示，译文完成后补上，不需要等翻译才出字幕。

翻译来源以实际识别结果为准。日文汉字不会因为外形像中文而直接转换成简体；中文中夹有 UE、Blender、Maya 等术语，也不会把整句强制当成英文翻译。切换目标时，上一目标的待处理结果会失效，缓存也按目标区分，避免迟到译文覆盖当前语言。

开启翻译时，“预览字幕”同时展示原文和译文各自的文字与背景样式，不等待模型。即使当前最多一行或仅显示译文，预览仍临时展示两套，结束后恢复原设置；隐藏字幕时预览保持隐藏。明确的单角色样式预览仍只展示对应角色。

## 准备本地翻译模型

翻译后端使用一个 M2M100 418M INT8 模型，支持中、英、日、韩相互翻译，不需要分别安装语言包或经过英文中转。识别后端保留当前 Whisper 等选项，不受翻译模型选择影响。

在“识别与翻译 → 实时翻译”点击“下载推荐翻译模型”，等待后台下载和校验成功后再打开翻译开关。首次获取需要网络；模型完整缓存后翻译在本机执行。模型缺失或不可用时明确提示，原文识别和显示继续。

已有兼容的离线包时，点击“导入本地翻译模型”，选择完整的 M2M100 CTranslate2 模型目录。分词器、模型架构、语言信息、许可与文件 SHA-256 都需要满足本程序校验要求；不能只选一个权重文件，也不能把 Whisper、NLLB 或 GGUF 直接当作兼容模型。所选目录保存到 `config.json` 的 `translation_model_path`，请保留原目录。

源码版也可在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 download_models.py translation
```

`m2m100` 是同一下载命令的别名。已有推荐包无需重复下载，程序会核验共享词表的语言标记；导入包只报告实际支持的方向。用户无需安装 PyTorch/Transformers 或自行转换模型。源语言标记和目标前缀由程序处理，这不等于支持模型卡中的所有翻译方向。完整格式、来源、许可和历史实测范围见 [翻译模型说明](translation-models.md)。

# 软件内更新

Windows 安装版点击底部“检查更新”，检查最新公开版本（包括明确标注的测试版）。检查成功且没有较新版本时显示“当前已是最新公开版本”；网络失败或发布信息不完整会显示错误，不会被当作已是最新版。

发现新版后，先显示当前版本、新版本、更新说明及随新版提供的完整许可条款。点击“同意条款并更新”后才下载安装包；选择“稍后”不会下载安装或关闭软件。许可原文可选中阅读，发布页面与许可文件也可单独打开。

下载安装包时检查文件长度、SHA-256 校验和及发布者 RSA/SHA-256 签名。签名同时绑定版本、文件名、大小、安装包摘要与条款摘要。地址限定为官方 Public 下载仓库的 HTTPS 资源。签名缺失、不匹配或文件损坏都会停止更新。

安装版保存当前设置，等待独立更新助手完成校验并确认就绪后正常退出。助手等待旧进程完全结束，显示覆盖安装进度，安装成功并核对版本后自动启动新版。无需重新逐页点击安装向导；不自动重启电脑。更新失败会显示说明并保留本次日志，可从发布页面手动下载后重新覆盖安装。缺少微软运行库等需要交互的先决条件，仍需通过普通安装向导处理。

高级设置中的“自动检查更新”默认关闭。启用后，在启动时和运行期间每小时检查；后台检查只读取版本、签名和条款元数据，确认前不会下载安装包或退出软件。控制窗口隐藏或最小化时，发现新版的提示延后到窗口再次显示。

配置、已下载或导入的模型、字幕记录继续保留在原位置。安装目录以当前运行的实际安装目录为准；更新不更改模型选择或用户配置。便携版会明确提示使用普通安装向导安装新版，原便携解压目录不会被静默覆盖。

源码运行不覆盖开发目录。macOS 当前仍通过“下载新版”打开发布页面，下载对应芯片版本后替换应用，保留 Application Support 中的配置和模型。

更新来源：[Public 下载仓库](https://github.com/occat666/occat-live-caption-download)。源码保留在独立的 Private 仓库；更新程序不需要访问 Private 仓库，也不携带 GitHub 账号凭据或发布私钥。

## 版本适用范围

以上为0.1.21安装版后续更新的流程。0.1.20及更旧客户端升级到0.1.21时，仍使用各自原有更新流程；安装0.1.21后，后续版本才采用新的同意、验签、覆盖安装与自动重启流程。macOS继续手动下载并替换DMG中的应用。


## 0.1.22 更新说明

本版改进字幕停留、历史记录与可选滚动；识别模型本身不变。0.1.21安装版支持同意后验签、覆盖安装并自动重启到0.1.22。0.1.20及更旧客户端到0.1.21的历史首次升级仍按旧流程。本版验证范围见同版发布说明。


## 0.1.23 更新说明

0.1.20及更旧客户端升级到0.1.21仍使用旧客户端流程；0.1.21安装版支持同意后验签，0.1.22和0.1.23延续这一更新方式。

从0.1.23起，“高级设置”改名为“字幕设置”；“自动检查更新”仍可在此页面开启。


## 0.1.24 更新说明

实时记录与悬浮字幕共用原文与译文两组外观；主面板顶部重复设置按钮已移除，可从左侧“字幕设置”进入。本版验证范围见同版发布说明。


## 0.1.25 更新说明

本版改进实时记录窗口的半透明背景及透明度调节；文字自身透明度与原译字幕背景设置继续独立。更新入口、同意条款、固定签名及覆盖安装流程延续上一版。本版验证范围见同版发布说明。


## 0.1.26 更新说明

本版候选修复实时记录最新多行字幕被底部裁切的问题；更新入口、同意条款、固定RSA签名和覆盖安装流程延续上一版。本版验证范围见同版发布说明。

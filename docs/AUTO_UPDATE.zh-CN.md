# 猫猫本地实时字幕：检查与安装更新

## Windows 安装版

1. 点击窗口底部“自动更新”，后台检查公开仓库 `occat666/occat-live-caption-download` 的版本列表及备用更新清单。已发布的公开测试版也会参加检查；Draft 不会参加。
2. 如果没有更高版本，显示“当前已是最新公开版本。”，不下载、不重装。
3. 如果有更高版本，下载统一的五语言 Windows x64 安装器，显示进度并验证文件大小和 SHA-256。失败时提示原因，保留当前软件，不运行安装器。
4. 校验通过后，再次验证安装包、保存配置，将当前实际安装目录和界面语言传给安装向导；确认安装器成功启动后才退出当前软件。按向导完成覆盖更新，保留用户数据目录中的设置、模型和字体，不重启 Windows。

更新任务可以在窗口隐藏到托盘后继续，但提示和启动安装器会推迟到窗口重新可见时。取消安装向导后，可重新打开原软件。

“高级设置 → 软件更新 → 打开软件时自动检查并安装更新”默认关闭。开启后，启动约 2.5 秒在后台检查一次；没有更新或检查失败时保持静默；发现新版后按相同下载、校验和安装流程处理，安装向导仍需确认许可。

## 其他运行方式

- Windows 便携版：可以检查、下载和校验更新，随后明确提示使用安装向导；不会把便携目录误当成安装目录直接覆盖。
- 源码运行：显示“当前从源码运行，请从下载页面安装新版。自动安装更新仅用于已安装的软件。”，不覆盖开发目录。这条说明不代表已完成版本检查。
- Mac 预览版：更新入口打开公开 Releases 下载页；下载匹配芯片的新 DMG 后替换 Applications 内的应用，用户设置和模型留在 Application Support。当前不支持应用内自动替换。

0.1.5 及更早的旧更新器只查询正式 Release，无法发现当前公开测试版，需要手动下载安装一次 0.1.6 或更新版本。后续可在安装版内检查公开测试版更新。

## 维护者发布约定

每个公开版本使用独立的 `vX.Y.Z` 标签，不复用旧安装器改名冒充新版本。安装器文件名为 `OCCAT-Live-Caption-X.Y.Z-windows-x64-setup.exe`，并提供 `SHA256SUMS.txt`；安装器必须只有一条有效校验记录。备用 `update.json` 只指向已经上传完毕且版本、大小与摘要完全一致的安装器和校验文件。

版本来自根目录 `VERSION`，构建参数 `-Version` 必须与之相同，冻结程序、Windows 文件属性、安装包和发布标签统一。同版本不会再次下载。正式版或公开测试版应准确反映实际验证范围；不为使旧更新器发现下载而假称稳定版。历史版本和原有安装包保持原样，第三方许可和对应源码材料随发布保留。

## 数据与校验

手动检查以及启用后的启动检查只访问公开 GitHub API、公开更新清单和官方资产地址，不读取浏览器登录、Cookie、令牌或 Private 仓库凭据，不上传音频、字幕或用户配置。

下载写入应用用户数据目录 `updates/` 的独立子目录；中断的临时文件和未安装的取消结果会清理。下载大小有上限，安装前在后台再次核对 SHA-256。HTTPS 地址限定官方 GitHub 主机与指定仓库初始下载路径；摘要用于校验完整性，不等同于 Windows 代码签名。

关闭应用或恢复默认并重启会取消未完成下载，不会继续在后台安装。更新不绕过向导中的许可与运行库先决条件。

## 0.1.10 公开测试版

本版继续使用同一检查与覆盖升级流程。0.1.9 安装版应能发现 0.1.10；已安装 0.1.10 时应提示当前已是最新公开版本，不重复下载安装。先完成全部附件上传与摘要核对，再发布 Release，最后更新公开 `update.json`；旧版本保留供回退。

本文保存现有详细使用说明；发布状态、许可证结论和安装验证范围以根目录 README 与同版发布说明为准。

## 单安装包与五种界面语言

新安装包统一为 `OCCAT-Live-Caption-X.Y.Z-windows-x64-setup.exe`，只下载这一份即可。双击后选择简体中文、繁體中文、English、日本語或 한국어 并按向导安装。进入软件后，在底部语言下拉框切换语言；无需重装，重开软件也保留选择。安装语言仅作为首次启动默认值，更新安装不会覆盖已有语言偏好。

界面语言与“识别语言”是不同设置。切换界面不改变音源、字幕原文、模型或翻译方向；实时翻译支持中、英、日、韩互译，中文目标可选简体或繁体。繁体、日语、韩语安装向导的许可页面使用已审阅的英文原文。旧分语言安装包（含 RC13）的用户，第一次迁移需手动下载新版统一安装包安装一次。

在「字幕外观 → 字幕自定义 → 文字」的字形选项中选择「中文（简体）」「中文（繁体）」或「保留原文（不转换）」。该选项决定中文原文的显示形式；中文译文按独立的“翻译目标”转换简繁，英文、日文、韩文原文和译文保持实际内容。字形、翻译目标与界面语言分别保存，升级保留旧版简繁偏好。

# 猫猫本地实时字幕 (Maomao Local Live Captions)

本地实时字幕工具，作者 OCCAT：捕获系统正在播放的声音，本地语音识别成文字；内容语言提供中文（简体）、中文（繁体）、英文、日文、韩文与自动判断，按模型能力提供可用选项。实时翻译默认关闭，打开后可在中、英、日、韩之间互译，中文目标可选简体或繁体。纯色或自定义图片控制台 + 置顶悬浮字幕，**识别与翻译在本机完成，音频不上传服务器**。


## 核心特性

- **本地识别与翻译**：基于 [faster-whisper](https://github.com/SYSTRAN/faster-whisper) 与 [CTranslate2](https://github.com/OpenNMT/CTranslate2)，翻译使用 M2M100 418M INT8；模型准备好后不需要远程推理接口
- **GPU 加速**：自动检测 NVIDIA GPU（CUDA），失败自动回退 CPU
- **WASAPI 环回捕获**：无需浏览器配合，任何播放器的声音都能抓
- **六种识别选项**：中文（简体）、中文（繁体）、英文、日文、韩文、自动判断；当前模型不支持的语种会禁用并说明原因
- **独立实时翻译 + 原文保留**：默认只识别原文，按开关启用中、英、日、韩互译，中文目标可选简体或繁体；两行模式可同时显示原文和译文
- **统一控制台**：PySide6 (Qt) 实现，固定模式使用纯色，自定义模式支持图片与玻璃质感设置；共享猫形字幕图标和柔和动效
- **字幕样式自定义**：字体、100～900 字重、8～200 磅字号、文字与背景颜色、透明度实时更新；按显示器与工作区比例定位
- **本地资产导入**：额外 TTF/OTF/TTC 字体，以及 CTranslate2 Whisper、sherpa-onnx int8 Paraformer/Fun-ASR-Nano 模型
- **回归与集成验证**：含中英文测试语音、真实模型加载、窗口交互及连续切页检查

## 下载与管理模型

我把识别模型和翻译模型放在同一个“模型下载”窗口里。你可以从“识别与翻译”中的“识别引擎”或“实时翻译”点击“模型下载与管理…”，直接下载，也可以打开官方、镜像的文件页面。

识别模型可选 Whisper Tiny、Base、Small、Medium、Large-v2、Large-v3、Large-v3-turbo，以及中文 Paraformer 和 Fun-ASR-Nano。把鼠标停在模型或同行按钮上，或用 Tab 聚焦，就能看到灰色小字简介。新安装默认选择 Large-v3-turbo，首次使用会联网下载约 1.6 GB，完成文件校验后加载；后续启动优先使用完整本地缓存。其他模型按需添加，中文为主可试 CPU 运行的 Paraformer，有 NVIDIA GPU 更适合用 Turbo 实时识别。手动下载的识别模型加入列表后，点击“应用并重载模型”开始使用。M2M100 翻译模型下载后会保存选择，实时翻译开关仍由你控制。升级保留已有模型选择和缓存。

下载来源可选自动、官方或镜像；网络连接可选系统代理、直连或自定义 HTTP/HTTPS 代理。自动模式遇到连接错误时会切换来源和连接方式。进度显示当前文件与已下载大小，可取消、重试和继续未完成的下载；完整文件经 SHA-256 校验后才会保存为可用模型。窗口中可查看模型保存位置或打开文件夹。

## 环境要求

- Windows 10/11（依赖 WASAPI）
- 当前依赖清单以 Windows x64 CPython 3.14.7 环境为依据；其他版本与全新机器仍需验证
- 可选：NVIDIA 显卡（CUDA）+ cuDNN（GPU 加速）
- 首次使用默认下载 Whisper large-v3-turbo 识别模型，需约 1.6 GB 空间及可用网络；也可导入兼容的本地模型。需要实时翻译时，再下载或导入 M2M100 418M INT8 翻译模型。两者分别负责语音转文字与文字翻译为所选目标语言

## 快速开始

从 [当前版本下载页](https://github.com/occat666/occat-live-caption-download/releases/tag/v0.1.21) 下载 Windows 安装器或便携包；macOS 用户选择与 Apple 芯片或 Intel 匹配的 DMG。安装与声音来源设置见 [README](../README.md)。应用开发源码仓库保持 Private，普通用户无需克隆源码、安装 Python 或运行开发命令。

启动后选择实际播放声音的设备或麦克风，等待默认识别模型下载并加载。需要翻译时，在“实时翻译”中下载推荐模型、选择目标语言并开启翻译。

也可直接在“识别与翻译 → 实时翻译”下载推荐模型或导入兼容的本地包，无需用户安装 PyTorch、Transformers 或运行转换命令。一个 M2M100 模型提供中、英、日、韩直接互译，中文目标可选简体或繁体，不再分别安装 Argos 语言包或通过英文中转。完整格式和限制见 [翻译模型说明](translation-models.md)；识别语言的能力限制见 [识别语言说明](recognition-languages.md)。

## 使用说明

本地运行的实时字幕工具：读取系统播放声音或选定麦克风，使用所选本地模型转成文字；内容语言可选择 **中文（简体）、中文（繁体）、英文、日文、韩文、自动判断**，可用范围取决于识别模型能力；中文两项共用中文识别模型，仅原文显示字形不同，切换简繁不重载识别。独立的“实时翻译”开关默认关闭；打开后使用 M2M100 418M INT8 在中、英、日、韩之间互译，翻译目标可选 **中文（简体）、中文（繁体）、英文、日文、韩文**。同语种直接显示，中文简繁通过本地转换处理，译文目标与原文字形分别保存。翻译模型缺失或不可用时明确提示，原文识别和显示仍继续。

## 启动与使用

1. 双击桌面「猫猫本地实时字幕」快捷方式，或本目录的 `启动实时字幕.bat`。
2. 在「识别与翻译」选择声音来源。通常选择「系统默认输出（自动跟随）」；需要会议发言字幕时，明确选择麦克风。
3. 选择识别语言，等待识别模型就绪，再播放视频或讲话。默认只显示原文；需要译文时选择翻译目标并打开“实时翻译”，译文在后台完成后更新，原文无需等待翻译。
4. 「暂停字幕 / 开始字幕」控制采集；暂停后可以恢复。「清空字幕」清除当前显示；「预览效果」检查样式。
5. 点击关闭叉或按 Alt+F4，选择「直接关闭」「暂存后台」或「取消」。暂存后台保留当前字幕运行状态；点击右下角通知区域的猫形字幕图标可恢复控制台，右键菜单可暂停/恢复字幕或「退出」。最小化保留任务栏入口。

声音来自耳机时，不要固定选择显示器的 HDMI 音频。固定设备不可用时界面会提示；默认输出模式会跟随 Windows 的默认播放设备。

## 界面与设置

黑夜、白天与跟随系统的固定主题使用均匀的小圆点背景；右上角不再叠加渐变波普图案。

控制页面采用圆角卡片、侧栏导航、开关、滑块和柔和动效。黑夜界面以 `#141414` 为窗口底色，卡片、输入框与菜单使用 `#181818`；普通按钮采用纯色填充，悬停、按下和键盘焦点通过整块底色反馈，无装饰边线或白雾叠层；下拉选中项及生效／按下按钮使用白底黑字。白天模式对应使用黑底白字，禁用文字灰色；跟随系统按实际明暗模式显示，自定义模式保留图片、材质和主题色。活跃控制台不绘制渐变。背景铺至窗口边缘，右上角使用 Windows 风格的横线、方框和关闭叉。拖动顶部空白区域可移动窗口，双击可最大化或还原，四边与四角支持缩放；最大化保留任务栏。支持 Tab 焦点和滚动设置页，控制台不强制置顶。

左侧采用 76 像素宽的紧凑图标栏，五个入口各有 52 × 52 像素点击区域、32 像素图标画布和集中的 2 像素圆头线条，入口间距为 4 像素。未选中项只显示矢量图标，悬停时也不增加底框；当前选中项才显示圆角小底框：白天为黑底白图标，黑夜为白底黑图标；自定义模式共用右侧卡片的透明玻璃，跟随透明度、模糊和背景压暗设置。自定义模式的默认图标与邻近界面文字完全同色，并跟随文字颜色设置；按下或选中时使用当前主题色，移开未选中图标、取消点击或切到其他入口后恢复文字色。固定模式的其余图标保留对应的黑白前景。滑动游标贴近窗口最左边缘，键盘焦点保持可见。鼠标悬停或键盘聚焦时，右侧浮出栏目名称。支持 Ctrl+1～5 快捷键，导航按钮固定在各自位置，悬停不切换页面，重复点击当前页保持选中。

图标栏左侧只有一个游标，默认在选中项旁显示小点。鼠标悬停或键盘聚焦入口时，小点伸成长条并上下滑到对应位置；鼠标移开后缩成小点、回到选中项。高度与位置共用 180 毫秒的 OutCubic 减速过渡，连续操作从当前形状衔接，点击即时切页，关闭动效后直接到位。页头、实时状态、设置卡片、页脚及侧栏与内容之间采用窄分隔，卡片内部保留舒适的文字和控件间距。按钮、声音来源/语言等下拉框、可选列表项和滑块使用手型光标；禁用项及空白区域使用默认箭头，文字输入区保留编辑光标。“同时显示原文”仅在实时翻译开启时可操作：关闭翻译后显示灰字、箭头光标，鼠标和键盘均不能切换；重新开启后恢复正常文字和手型光标，保留之前的原文显示偏好。

连续切页复用同一套过渡层和动画，结束时立即释放截图，避免快速点击在事件队列中堆积大量旧截图。通过桌面快捷方式静默启动时，未处理的界面异常与原生崩溃堆栈也会尽可能写入 `error.log`，便于定位偶发问题。

「页面外观」提供黑夜、白天、跟随系统、自定义四种模式。只有“自定义”展示背景图片选择入口，允许选择或更换本地图片；其余三种模式使用固定的明暗配色，不读取或显示保存的图片。已选图片路径会保留，切回自定义后可继续使用；在选图期间切出自定义，迟到的选择结果不会更改模式或背景。玻璃材质按当前配色或自定义图片绘制，不会实时显示窗口后面的其他应用。

仅可点击的按钮、开关图形、输入框操作区和可用菜单项有对应反馈。卡片、说明文字、空白区域、禁用项不高亮。滑块轨道在调节时不变色，仅当前位置圆点以 120 毫秒 OutCubic 动画轻微放大和描线；拖动数值即时生效，不对数值做延迟动画。弹层打开、关闭或窗口失活会清理旧反馈。关闭页面动效时反馈立即变化，不继续运行空闲动画。

小型开关的鼠标点击、手型光标与悬停反馈均限制在可见的胶囊图形内，包括「窗口与待机」中的置顶、锁定和鼠标穿透。文字标签、圆角外侧和整行留白不会触发开关；键盘 Tab/空格仍可使用，禁用状态仍保留箭头与灰字。

顶部仅最小化、最大化和关闭按钮显示各自的小型圆角高亮框，标题栏空白区域不显示整条透明高亮。

自定义模式的主题色实时应用并自动保存，固定配色模式使用内置黑白色。已选主题色保留，切回自定义模式再生效；“重置为自动”恢复随自定义背景配色。品牌图标始终保持单色。颜色选择框不阻塞字幕更新，取消选择保留原色。

Windows 控制窗口的启动、关闭、最小化和恢复使用系统原生窗口路径，遵循 Windows 的动画与辅助功能设置；实际过渡由系统版本及设置决定。Windows 11 使用系统圆角，Windows 10 使用系统方角。macOS 保留现有滑入与折叠过渡。可在「页面外观」关闭「悬停动效与页面过渡」；该开关不修改 Windows 系统动画设置，也不改变字幕外观或采集状态。

macOS 的启动过渡结束后，先绘制真实窗口，再撤下覆盖画面。点击左侧不同导航项或使用 Ctrl+1～5 切到另一页时，页面标题与目标页当前可见的设置卡片依次渐入；卡片中的文字、列表和控件作为整体出现。标题立即开始、持续 180 毫秒；卡片从上到下延迟 35/80/125/170 毫秒开始、各持续 230 毫秒，第四张及以后共用最后一档，整体最长 400 毫秒。各段使用 OutCubic 减速缓动，旧页面在前 120 毫秒淡出。实时状态、通用操作按钮和页脚持续显示。

同页重复点击不重播。快速连续切换从当前显示画面继续，以最后选择的页面为准；只保留一个过渡层、一条动画和固定数量的页面图像，不给每个控件添加动画或透明度效果。输入、点击、滚动、悬停移动、程序滚动、布局变化、改变窗口尺寸或主题时，会结束过渡并立即显示真实控件；隐藏或关闭时释放缓存。关闭「页面动效」后直接切换。卡片间仍留出 16 像素，数值标签与输入行之间至少留出 8 像素。

后台猫形字幕图标用播放/暂停标记区分运行状态；与桌面、窗口和底部入口保持同一单色造型。选择退出时使用电源标记，随后移除图标并结束程序。Windows 可能将新通知图标收入右下角的上箭头区域，其显示位置由系统管理。

Windows 安装版点击底部“检查更新”，先阅读更新说明及随新版提供的条款，确认后下载并校验，保存设置后自动覆盖安装，成功后重新启动。字幕设置的“自动检查更新”默认关闭，启用后启动时及每小时只检查元数据，确认前不下载、不安装。模型与配置保留；便携版使用普通安装向导。macOS 仍通过发布页面下载并替换应用。

开启实时翻译后，“预览字幕”同时展示原文与译文两套样式，使用示例文字，不加载翻译模型。预览时即使选择了仅译文或最多一行，也会临时展示两套，结束后恢复原来的排版；隐藏字幕时预览也保持隐藏。明确的单角色样式预览仍可只展示对应角色。

“内容语言”的中文（简体）与中文（繁体）使用同一中文识别能力，仅改变中文原文的显示形式；在这两项之间切换不重载识别模型。“翻译目标”可独立选择中文（简体）、中文（繁体）、English、日本語或한국어，中、英、日、韩可互译；简繁转换在本地完成。译文目标独立于界面语言及原文字形设置，切换后旧目标的迟到结果会被丢弃。推荐的本地 M2M100 模型可复用，导入包则按实际词表能力检查。

“暂停字幕”旁新增“隐藏字幕”。点击后两层字幕窗口都隐藏，识别、翻译及已有记录设置继续运行，按钮变为生效配色并显示“显示字幕”；再次点击恢复当前内容。隐藏状态只用于当前运行，重新打开软件默认显示。窗口窄或英文标题较长时，操作按钮整行移到标题下面，隐藏按钮始终紧邻开始／暂停按钮，不挤压标题。

关闭确认弹窗使用相同主色：白天为黑色、黑夜为白色、自定义为用户选择的主题色。“直接关闭”采用 100% 主色，“暂存后台”采用 50% 主色，文字按实际合成底色选择清晰的黑／白；“取消”保留普通按钮样式。禁用的后台操作不显示生效高亮。

「字幕外观 → 文字描边与阴影」分别提供两个开关，默认关闭。描边粗细 0–12 像素，阴影柔化 0–24 像素、水平/垂直偏移 −32–32 像素，步进均为 1；阴影不透明度 0–100%，描边与阴影颜色自由选择。开启后立即作用于字形轮廓；底衬按文字本身和留白计算，描边与阴影不改变底衬的大小和位置。极小工作区会缩减实际特效边距避免裁切，保存值保持不变，移回较大屏幕后恢复。外观版本保存、重启与恢复默认设置均包含这些参数。

描边采用圆滑转角和轻量边缘羽化，投影沿完整文字轮廓平滑衰减，保留连续透明度以自然融入不同背景。阴影柔化设为 0 时保留清晰投影与边缘抗锯齿；增大柔化值可获得更柔和的过渡，文字本身保持清晰。

图片支持 PNG/JPEG/WebP/BMP，按 EXIF 方向校正，居中等比铺满；为控制内存占用，单张图片上限为 4000 万像素。图片保留在原路径，请不要移动已选文件。图片文件无法读取时回到固定黑夜配色。

页面设置单独保存到 `ui_theme.json`，字幕设置保存到 `config.json`。Ctrl+1～5 切换页面，Alt+P 暂停/恢复，Alt+V 预览字幕；页面动效可以关闭。

左侧五个图标共用一个滑动游标。鼠标悬停或用键盘聚焦时，右侧浮出栏目名称，未选中图标保持统一前景，只有选中项显示小底框；白天、黑夜使用反色图标，自定义使用右侧同款透明玻璃；默认图标跟随界面文字色，按下或选中图标使用主题色。点击时轻微下沉并回弹。关闭页面动效后，状态直接切换。语言下拉框位于底部，支持中文（简体）、中文（繁体）、English、日本語和한국어。导航与窗口控件使用 Feather 官方矢量图标，原始许可位于随附 licenses/feather/LICENSE。

设置页使用鼠标滚轮时短时平滑移动，触控板按像素直接跟随。到顶部或底部时停靠，不使用越界弹簧回弹；反向输入、拖动滚动条、键盘定位或切换页面会接管并取消尚未完成的滚轮位移。关闭页面动效后，滚轮采用即时移动。

- **识别与翻译**：声音来源、刷新设备、识别模型与计算设备、应用重载、本地识别模型导入和模型下载、中文（简体）/中文（繁体）/英文/日文/韩文/自动判断、独立实时翻译开关与五种目标语言、原文保留、推荐翻译模型下载与本地翻译模型导入；旧“中英混合”配置迁移为“自动判断”。
- **字幕外观**：系统/导入字体、字重、字号、文字颜色与不透明度、描边和阴影；随文字伸缩的底衬、左右/上下留白、背景颜色与不透明度、圆角；行数及超长字幕缩字。
- **窗口与待机**：显示器、百分比位置、置顶、锁定、鼠标穿透、待机提示及动画。
- **字幕设置**：隐藏与渐变、字幕记录、恢复默认设置并重启。
- **页面外观**：只控制软件页面的背景、玻璃不透明度、模糊、压暗、圆角与动效。

外观设置即时生效并保存；旧版 `ui_theme.json` 中选择的背景模式和图片路径会继续保留。页面主题不会改动字幕区域；只有在「字幕外观」等页面主动修改字幕设置时，才会更新对应字幕效果。模型/计算设备的改动通过重载模型应用。GPU 自动模式可在初始化失败时回退 CPU，CPU 速度取决于硬件和模型大小。

字幕最多显示一行或两行。设置为一行时优先显示目标语言译文，译文尚未就绪时先显示原文；设置为两行且开启“同时显示原文”时，原文在上、目标语言译文在下。关闭实时翻译或没有译文时按行数设置显示原文；关闭“同时显示原文”后，译文就绪时仅显示译文。

「字幕外观」分为原文自定义与译文自定义两块，文字及背景分别设置。原文和译文的背景可以同时开启、仅开启任意一侧或全部关闭；各自的颜色、不透明度、左右及上下留白、圆角独立保存。升级时，旧版共用的背景设置先继承到两侧，之后互不联动。位置、行间距和最多行数共用，开关背景不移动文字；没有译文时不绘制空白译文框。文字和背景的不透明度分别控制，背景为 0% 时文字仍显示，圆角只裁切背景。字幕整体同步移动、淡入淡出、隐藏与退出；这些设置独立于控制页面外观。

解锁字幕时会临时解除鼠标穿透；重新锁定时恢复原有穿透状态。解锁后拖动字幕，松开即可保存显示器与位置。字幕窗口收到鼠标事件时可以用滚轮调字号，Shift + 滚轮调整高度并保存。

## 自定义字幕与导入

「字幕外观」的原文与译文自定义区各自提供背景开关及以下参数。数值支持滑块、精确输入框，以及聚焦后的方向键；改变后实时生效并自动保存到 `config.json`。滚轮仍用于滚动设置页面。

| 参数 | 范围 / 步进 | 初始默认值 |
| --- | --- | --- |
| 左右留白（每侧）`bg_padding_x` | 0～240 像素 / 1 像素 | 26 像素 |
| 上下留白（每侧）`bg_padding_y` | 0～240 像素 / 1 像素 | 11 像素 |
| 圆角半径 `bg_radius` | 0～240 像素 / 1 像素 | 10 像素 |
| 背景颜色 `bg_color` | `#RRGGBB` / 颜色选择框 | `#141414` |
| 底衬不透明度 `bg_opacity` | 0%～100% / 1% | 60% |

底衬始终自动包裹字幕：宽度 = 文字块宽度 + 左右留白 × 2；高度 = 文字块高度 + 上下留白 × 2。字体、字号、字重、字幕长度或行数变化时，底衬立即重新计算大小；同一角色的多行文字共用一个底衬，原文与译文分别围住各自的文字并居中。只需调整边框距离文字的水平和垂直距离，无需单独设置固定宽高。旧配置中的固定 `bg_width` / `bg_height` 会被忽略并在下次保存时移除，现有留白、字体和颜色设置保留。

实际尺寸不超过显示器工作区。接近屏幕边界时对称压缩留白，保存的留白值保持不变；文字换行、长句自动缩字仍由字幕最大宽度、行数和屏幕可用空间控制。字体改变会带动底衬尺寸变化，但不会重置所选圆角、留白、颜色和透明度。

圆角 0 表示直角；实际圆角取设置值与底衬宽、高各一半中的最小值。例如 400×60 的底衬、设置圆角 80，实际使用 30 像素，保存值仍为 80。底衬随文字变大后，会按保存的圆角值重新绘制。

「字幕设置 → 恢复默认设置并重启」会先显示非阻塞确认框，取消不改变设置。确认后备份当前配置，将字幕/识别配置和页面外观配置恢复为程序中的 `main.DEFAULTS`、`ui_material.DEFAULTS`，再退出并重新启动；重启后重新读取默认配置并建立界面、字幕层与识别工作线程。字体默认自动选择、36 磅、字重 700、白色、文字不透明度 100%；底衬按上表恢复，默认显示背景。位置恢复默认底部居中、距底部 90 像素；模型恢复 `large-v3-turbo`、计算设备自动、语言自动判断、实时翻译关闭。页面恢复跟随系统、自动字体与主题色、默认动效。完整默认值由代码中的同一份常量提供，避免重置逻辑另抄一份后产生差异。

重置保留导入的字体和模型文件、模型登记、外观版本以及字幕记录，只恢复选择项与功能设置；也不会删除背景图片。字体/模型导入或外观版本保存进行中暂不执行重置。保存或启动新进程失败时显示错误并保留原设置，防止只恢复一半；旧实例退出后新实例才重新获取单实例锁。

「保存外观版本」位于「字幕设置 → 恢复默认设置」卡片中，紧邻「恢复默认设置并重启…」右侧，间距 10 像素，沿用同一按钮样式。点击即保存，不弹出额外确认、不重启。保存范围为当前页面外观（背景模式和图片路径、颜色、透明度、模糊、圆角、字体、动效等）及字幕字体、底衬、位置、排版和显示过渡参数；不包含识别模型、音频设备或字幕内容。

每次在程序目录的 `appearance-versions` 中生成新的 `appearance-年月日-时分秒-微秒-随机标识.json`，内含版本名、北京时间、格式版本号、`page` 与 `caption` 参数。保存的是点击时的内存值，包括尚未自动落盘的修改；后台完整写入后才发布为正式版本，不覆盖现有版本。过程中按钮暂时禁用并提示「正在保存外观版本…」；完成后下方显示「已保存」、版本名和可选中复制的完整文件路径；失败显示原因和「请重试」，按钮恢复可用。当前配置继续生效。

外观版本仅保存参数，图片与字体记录引用，需保留对应原文件或已安装字体；它不复制图片、字体和模型文件。该按钮提供版本保存，当前未新增版本列表或一键载入入口。

「字幕外观」的字体、字重与字号支持精确数值输入，也可拖动滑块；颜色可输入 `#RRGGBB` 或通过颜色选择框实时预览，取消选择恢复原色。字重范围为 100～900，字号为 8～200 磅；字体没有某档字重时，使用最接近的字面。大字号在小屏幕上会按可用空间缩小，长待机提示会省略，避免文字或动态圆点被裁切。

「窗口与待机 → 屏幕与位置」可选显示器、设置水平与垂直位置，或一键底部居中。0% 对齐工作区左/上边缘，100% 对齐右/下边缘，50% 居中；定位会扣除字幕自身尺寸与任务栏。旧像素偏移保持原位，第一次调整百分比时转换为相对位置。拔掉选定显示器时回到可用屏幕；保存的显示器标识继续保留，重新连接后可恢复。

「字幕外观 → 导入字体文件」支持 TTF、OTF、TTC。文件先在后台校验，再复制到应用目录的 `fonts/user`；相同内容自动去重，不覆盖同名字体。导入后自动选中新字体，重启时重新加载。字体仅注册到本程序，不安装为系统字体，也不需要管理员权限。

软件提供 HarmonyOS Sans、MiSans、思源黑体、思源宋体四种字体，共 30 个未经修改的官方字重。字幕字体与界面字体均按家族显示，每个家族只出现一次，思源黑体粗体等旧名称归入思源黑体，粗细在字重选项中调整。可在「页面外观 → 界面字体」选择；字重列表跟随当前字体，默认思源黑体 Medium，切换字体时尽量保留相同样式名称。正文和说明在自然字距上增加约 0.15 像素空隙，输入框与按钮保持自然字距；标题适度收紧并启用字偶距，多行说明保留充足行距。其他字体请自行下载后导入；既有本机字体选择继续保留。「字体来源与许可…」提供官方来源和随附原许可，软件不安装系统字体，不导出用户字体或自定义图片。

「识别与翻译 → 识别引擎」提供识别模型列表。点击「导入本地模型目录…」并选择已解压的完整目录，后台自动识别并校验模型格式，成功后加入上方列表；点击「应用并重载模型」才会切换正在使用的模型。无法判断格式、文件不完整或同一目录混有多种模型时显示具体错误并保留当前选择。模型加载和识别继续在后台线程运行。模型类型和目录记录在 `imported_models.json`，权重保留在原位置，不复制大文件，请勿移动或删除已导入目录。

| 模型类型 | 目录中必须包含 |
| --- | --- |
| Whisper / faster-whisper（CTranslate2） | `model.bin`、`config.json`、`tokenizer.json`、`preprocessor_config.json`，以及 `vocabulary.json` 或 `vocabulary.txt` |
| Paraformer 中文（sherpa-onnx int8） | `model.int8.onnx`、`tokens.txt` |
| Fun-ASR-Nano（sherpa-onnx int8） | `encoder_adaptor.int8.onnx`、`llm.int8.onnx`、`embedding.int8.onnx`，以及 `Qwen3-0.6B/vocab.json` 与 `merges.txt` |

导入按上述后端格式校验；任意 `.pt`、`.pth` 或其他架构的 ONNX 文件需要先转换为受支持的完整模型包。真实权重兼容性在后台加载时检查，错误会显示在状态区；已导入模型失联时不会把本地标识交给在线下载流程。

上述列表只用于语音识别模型。M2M100 属于文字翻译模型，使用“识别与翻译 → 实时翻译”内单独的“导入本地翻译模型”入口；不能把两类模型因都含 `model.bin` 就混用。选择保存到 `config.json` 的 `translation_model_path`，下次启动继续使用该目录。翻译导入只接受符合本程序清单、分词器及校验要求的 M2M100 CTranslate2 模型包，详见 [翻译模型说明](translation-models.md)。

字体与模型的 Windows 选择窗口复用图片选择窗口的布局、详细列表、圆角控件与暗色配色。均以非阻塞方式打开，字幕在选择、校验与模型加载期间仍可更新。左侧导航与右侧控件统一样式，页面渐入效果继续保留。

## 核心流程

`Windows WASAPI → 连续重采样到 16 kHz → 按音频样本切句 → faster-whisper → 结果队列 → 字幕窗口`

`实时翻译已打开：中/英/日/韩识别结果 + 所选翻译目标 → M2M100/CTranslate2 翻译工作线程（同语种直通、中文简繁本地转换）→ 译文目标与当前句校验 → 更新字幕`

暂停、切换设备、清空、重载时隔离上一轮结果，防止迟到字幕或译文覆盖新内容。翻译不在界面主线程执行。字幕记录先保存原文，译文完成后追加关联记录，避免翻译失败导致整句丢失。

译文显示同时核对会话、句子编号、翻译请求和原文。开始下一句、字幕自动隐藏或切换翻译开关后，已失效的旧译文不能重新上屏；连续长句的正常切块仍能产生译文。该校验处理显示时序，不改变字幕字体、颜色、位置或布局。

控制面板使用 PySide6（Qt），字幕浮层保留 Tk 窗口，文字通过 Qt 字体引擎生成位图以支持多档字重；测量和绘制使用同一套字形。两者在同一主线程中通过非阻塞事件桥协作；所有会操作 Tk 的控制台回调先入队，在 Qt 派发结束后执行。

识别与翻译在本机执行，音频不上传。程序不播放测试语音、不朗读字幕、不做语音合成。首次缺少默认 Large-v3-turbo 模型时会联网下载并校验；其他模型可通过“模型下载与管理…”按需添加，也可准备兼容本地文件或运行 `download_models.py`。已经完整缓存的模型优先从本地读取。

## 字幕停留、历史与滚动显示（0.1.22）

在字幕设置的「字幕停留与过渡」中选择「普通字幕」或「滚动字幕」。普通模式保留近期阅读上下文；滚动模式保留最近2至5组，每组原文和译文各自使用原有样式与背景。

「无新字幕后自动收起」最长30秒，从最后可见的新内容计时；「最少阅读时间」保证短句的基础阅读时间，长句自动延长。开启「无新字幕时持续保留」后，实际字幕保持显示，直到新内容替换或手动清空、暂停；预览和等待提示使用各自的行为。

点击顶部「历史字幕」或字幕设置「查看历史字幕」，可查看本次启动以来最近500条识别终稿。临时识别变化不会重复入列，译文晚到时补回对应条目。上翻或选中文字会暂停跟随，点击「回到最新」恢复；可复制选择的文字或全部记录，也可清空本次历史。关闭历史窗口不清除记录，退出软件后本次内存历史结束；原有按日期保存本机字幕的选项仍独立生效。


## 悬浮字幕与实时记录（0.1.23）

点击控制台上方醒目的「字幕设置」按钮，或按 Ctrl+4，在页面顶部选择：

- 「悬浮字幕」：在屏幕底部显示当前对话，沿用已有的普通／滚动字幕、原文／译文独立样式。
- 「实时记录」：打开便于阅读的对话记录窗口，按时间逐句排列原文与译文。原文为次要行，译文为较大主行；没有译文时直接阅读原文。适合看直播、电影，能够知道正在说什么，也能回看上一段。

实时记录窗口可选择「置顶」，调整大小，拖到视频旁边。新内容自动跟随到底部；向上翻阅或选中文字时暂停跟随，点击「回到最新」恢复。窗口内也有「字幕设置」入口。

切换模式保留本次运行的最近500条终稿，不重启模型或声音捕获。正在识别的文字显示在记录区下方，终稿才进入历史；晚到的译文补回原句。预览不写入历史。关闭或隐藏记录窗口仅隐藏显示，识别和翻译继续；点击「显示字幕」或重新选择「实时记录」即可恢复。清空记录后，旧译文不会重新插回。

「保存识别原文与译文到本机」仍独立控制按日期保存到 captions 文件夹；开关保持原来的选择。窗口内历史保留本次运行最近500条，退出软件后可到已保存的本机文件中回看。关闭本机保存时，本次窗口历史仍可使用。

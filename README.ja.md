**OCCAT** です。Windows で動作するローカルリアルタイム字幕ツールを作りました。パソコンで再生している音声や、マイクで拾った話し声をフローティング字幕として表示できます。必要に応じて、英語・日本語・韓国語を中国語に翻訳することもできます。動画の視聴、講義、ゲーム、ライブ配信、個人での会議などで、内容を読み取る補助としてお使いください。

## できること

- システム音声とマイク入力に対応。認識モデルの対応範囲に応じて、中国語・英語・日本語・韓国語または自動判定を選び、フローティング字幕を表示できます。
- リアルタイム翻訳は個別にオン・オフでき、原文も同時に表示できます。認識エンジン、翻訳、モデル管理は「识别与翻译」（認識と翻訳）ページにまとめています。
- モデルの説明とおすすめのヒント、公式・ミラーのダウンロード先、ワンクリックダウンロード、途中からの再開、ファイル検証、ローカルモデルのインポートに対応しています。
- 字幕のフォント、太さ、サイズ、色、縁取り、影、位置、背景を調整できます。外観設定を保存し、必要なときに復元することもできます。中国語字幕の字体は簡体字・繁体字・原文を保持から選べ、中国語の原文と訳文の両方に適用されます。
- 画面とインストーラーの言語は、简体中文、繁體中文、English、日本語、한국어 の 5 種類。画面の言語、中国語字幕の字体、音声認識の言語はそれぞれ別に保存されます。
- 画面用フォントとして HarmonyOS Sans、MiSans、思源黑体（Source Han Sans）、思源宋体（Source Han Serif）を用意し、それぞれ本来のウェイトから選べます。ローカルの TTF・OTF・TTC フォントのインポートにも対応しています。
- ダーク、ライト、システムに合わせる、カスタムの各テーマに対応。カスタム背景とガラスの透明度・ぼかし・暗さの設定は連動します。ナビゲーションアイコンは通常時に文字色に従い、押下時・選択時にテーマ色になります。
- 5 つの Feather ベクターアイコン、ホバー時の名前表示、1 つのスライド式インジケーターを備えています。Tab キーでの移動、Ctrl+1～5 でのページ切り替え、画面アニメーションの無効化にも対応しています。
- 字幕の一時停止・プレビュー・非表示、ウィンドウのクリック透過、待機、トレイからの操作、正式版の更新確認に対応。設定ページはマウスホイールとタッチパッドでスクロールできます。

今回の変更・修正内容は [0.1.5 リリースノート](https://github.com/occat666/occat-live-caption-download/releases/tag/v0.1.5)に掲載しています。

## 0.1.5 の変更点

- 認識モデルの初回ダウンロード、読み込み、ウォームアップの各段階を字幕オーバーレイにも表示します。モデルの準備が整う前に「音声入力を待機中」と表示しなくなります。
- モデルの読み込みに失敗した場合は対応するエラーを表示します。準備完了後は選択中の音声入力に自動で接続し、接続後に待機状態へ移ります。初期化を続けるためにアプリを再起動する必要はありません。
- 完全なモデルキャッシュは引き続きローカルで読み込み、再ダウンロードしません。初回ダウンロード完了時は、自動で読み込みを続けることを案内します。テーマ色の設定はカスタムモードだけに表示します。

**[0.1.5 公開テスト版を開く](https://github.com/occat666/occat-live-caption-download/releases/tag/v0.1.5)**。これは **prerelease（プレリリース版）**です。[前の 0.1.1](https://github.com/occat666/occat-live-caption-download/releases/tag/v0.1.1) は以前の版に戻すために残しており、その他の旧版も Releases から入手できます。

インストーラー版とポータブル版は、**どちらか一方を選んでください**。リポジトリ全体やすべての ZIP をダウンロードする必要はありません。

1. **Windows 10/11 x64** と Microsoft Visual C++ x64 ランタイム **14.44.35211 以降**が必要です。ランタイムが未導入または古い場合、インストーラーは確認後に Microsoft の公式サイトからダウンロードし、署名を検証してランタイムのインストール画面を開きます。Microsoft のライセンスと管理者権限の確認に従ってください。完了後、字幕アプリのインストールが自動的に続行されます。このダウンロードにはインターネット接続が必要です。Windows が自動的に再起動されることはありません。Microsoft から再起動が必要と案内された場合は、作業を保存して自分で再起動し、字幕アプリのインストーラーを再実行してください。ポータブル版でもランタイムの事前導入が必要です。
2. インストーラー版は EXE をダブルクリックし、簡体字中国語・繁体字中国語・英語・日本語・韓国語を選んでウィザードに従ってください。ポータブル版はすべて展開してから起動し、EXE だけを取り出さないでください。インストーラーには商用のコード署名証明書を使用していません。ダウンロード元と SHA-256 を確認してください。
3. 「猫猫本地实时字幕」を起動し、実際に音声を再生している出力デバイス、またはマイクを選びます。新規ユーザーの既定は **Whisper large-v3-turbo** です。初回はネット接続が必要で、約 **1.6 GB** をダウンロードしてファイルを検証します。途中からの再開とダウンロード先の切り替えに対応し、完全なキャッシュがあればローカルから優先的に読み込み、オフラインでも使えます。ほかの 8 つの認識モデルは必要に応じてダウンロードするか、互換性のあるローカルモデルをインポートしてください。更新は保存済みのモデル選択を上書きしません。
4. 翻訳が必要な場合は、「识别与翻译」（認識と翻訳）で互換性のある **M2M100** モデルをダウンロードまたはインポートし、「实时翻译」（リアルタイム翻訳）をオンにしてください。原文だけを表示する場合はオフのままで使えます。
5. 「字幕外观」（字幕の外観）で字幕スタイルを、「窗口与待机」（ウィンドウと待機）で位置・クリック透過・待機方法を調整できます。画面下部の言語メニューは简体中文、繁體中文、English、日本語、한국어 に対応し、認識言語は別に設定します。中国語字幕の字体は「字幕外观 → 文字」（字幕の外観 → テキスト）で設定でき、画面の言語を切り替えても変わりません。

ソフトウェアのバージョンは **0.1.5**、リリースタグは **`v0.1.5`** で、引き続きプレリリース版として提供しています。**テスト版は GitHub の latest 正式版 API 経由では配信されません。Releases から手動でダウンロードしてください。** 以前の言語別インストーラーを使っている方も、上記の共通インストーラーで手動更新できます。繁体字中国語・日本語・韓国語のインストールウィザードでは、確認済みの英語のコンポーネント規約を原文のまま掲載しています。

ユーザー単位でインストールされ、既存の設定が優先されます。インストーラー版・ポータブル版ともに、設定・ダウンロードしたモデル・字幕記録を `%LOCALAPPDATA%/OCCATLiveCaption` に保存します。アンインストールしてもユーザーデータは残ります。ポータブル版も、展開先のフォルダーに設定を保存する方式ではありません。

**旧版から更新する場合：** 保存済みのモデル選択とほかの設定を維持します。更新後も Base が選ばれている場合は、「認識と翻訳 → 認識エンジン → 認識モデル」で `large-v3-turbo` を選び、「適用してモデルを再読込」を押すと、Turbo をダウンロードして使えます。新規ユーザーの既定は Turbo です。

## 検証範囲と利用について

今回は初回起動の状態表示、読み込み失敗、準備完了後の音声自動接続、一時停止と再読み込み、古いイベントの除外を重点的に検証します。

**関連する単体チェック 155 件**、凍結アプリの起動状態、および 5 言語すべての隔離インストール、オフライン画面起動、アンインストールの検証に合格しました。ソース実行版と凍結版の両方で、**ローカルに完全にキャッシュされた Turbo モデルを使い、CPU で音声テストデータの実際の認識**を行い、認識子プロセスの終了も確認しました。モデルの新規ダウンロードを確認するテストではありません。今回はモデル全体の再ダウンロード、現場の生音声の収録、報告者のハードウェアやランタイムのないクリーンな Windows での検証は行っておらず、すべての機器やネットワーク構成の動作を認証するものではありません。Windows ファイルバージョン **0.1.5.0** はビルド報告の凍結アプリ検証結果で確認しました。

**ランタイムが入っていないクリーンな Windows 環境での実機検証はまだ行っておらず、引き続きプレリリース版です。** これらの確認によって、あらゆる GPU、複数ディスプレイ、音声デバイス、システムの組み合わせでの動作を保証するとは考えていません。

認識と翻訳はパソコン内で実行されます。初回の認識モデル、必要に応じた翻訳モデルのダウンロードと更新確認にはネットワークを使用します。完全なキャッシュがあれば、モデルはオフラインで使えます。**字幕テキストは初期設定でローカルに保存されます**。詳細設定で保存をオフにできますが、オフにしても過去の記録は削除されません。個人の背景画像や、自分でインポートしたモデル・フォントは公式インストーラーに含まれません。

字幕や翻訳には誤りが生じる可能性があります。重要な内容は人の手で確認してください。このツールは読み取りを補助するもので、専門のアクセシビリティサービスや正式な記録に代わるものではありません。利用する権利のある内容だけを処理し、他の人の発言を取り込む前に必要な許可を得てください。

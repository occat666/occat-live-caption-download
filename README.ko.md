안녕하세요, **OCCAT**입니다. 제가 만든 Windows용 로컬 실시간 자막 도구와 macOS 네이티브 미리 보기 버전을 소개합니다. 컴퓨터에서 재생되는 소리나 마이크로 입력한 음성을 화면 위에 떠 있는 자막으로 표시합니다. 필요할 때는 영어, 일본어, 한국어를 중국어로 번역할 수도 있습니다. 동영상 시청, 강의 수강, 게임, 라이브 방송 시청, 개인적으로 참여하는 회의 등에서 내용을 읽고 이해하는 데 활용할 수 있습니다.

## 0.1.12 업데이트

- 실시간 자막 처리와 표시의 대기를 줄이고, 짧은 자막과 독립 원문·번역 트랙 및 수신 전문 로그를 유지합니다.
- 속도는 모델과 하드웨어에 따라 달라집니다. 지연 없음, 단어 단위 시간 정렬, 처리 지연으로 건너뛴 오디오 복원은 보장하지 않습니다.


## 0.1.11 업데이트

- 긴 자막을 문장 부호와 읽기 쉬운 길이에 따라 나누고, 짧은 단위로 순서대로 표시합니다.
- 원문과 번역은 별도 표시 트랙에서 진행되며 각각의 스타일을 유지합니다. 단어 또는 문장 단위의 시간 정렬은 보장하지 않습니다.
- 새 인식 구간은 이전 구간을 대체하므로 화면에 오래된 문장이 쌓이지 않습니다. 지우기, 일시정지, 미리 보기 및 세션 변경은 이전 표시를 정리합니다. 자막을 숨겨도 인식은 계속되며 다시 표시하면 현재 읽기 위치가 나타납니다.
- 로컬 자막 로그에는 수신한 인식 및 번역 전문을 보존합니다.


## 주요 기능

- 시스템 오디오와 마이크 입력을 지원합니다. 인식 모델의 지원 범위에 따라 중국어, 영어, 일본어, 한국어 또는 자동 감지를 선택하고, 결과를 플로팅 자막으로 표시할 수 있습니다.
- 실시간 번역을 별도로 켜고 끌 수 있으며 원문도 함께 표시할 수 있습니다. 인식 엔진, 번역, 모델 관리는 “识别与翻译”(인식 및 번역) 페이지에 모았습니다.
- 모델 설명과 추천 안내, 공식·미러 다운로드 경로, 원클릭 다운로드, 이어받기, 파일 검증, 로컬 모델 가져오기를 제공합니다.
- 자막 글꼴, 굵기, 크기, 색상, 외곽선, 그림자, 위치와 배경을 조절하고 모양 설정을 저장·복원할 수 있습니다. 자막 글리프는 중국어 간체, 중국어 번체, 일본 글리프, 한국 글리프, 원문 유지의 다섯 가지입니다. 간체·번체 변환은 중국어에만 적용합니다. 일본어·한국어는 내장된 지역별 Source Han 글꼴로 원문을 표시하며, 내용을 일본어나 한국어로 번역하지 않습니다.
- 화면과 설치 프로그램은 简体中文, 繁體中文, English, 日本語, 한국어의 다섯 가지 언어를 지원합니다. 화면 언어, 자막 글리프, 음성 인식 언어는 각각 따로 저장합니다.
- 화면 글꼴로 HarmonyOS Sans, MiSans, Source Han Sans(思源黑体), Source Han Serif(思源宋体)를 제공하며, 각 글꼴에서 원래 제공하는 굵기를 선택할 수 있습니다. 로컬 TTF, OTF, TTC 글꼴 가져오기도 지원합니다.
- 어두운 테마, 밝은 테마, 시스템 설정 따르기, 사용자 지정 테마를 제공합니다. 사용자 지정 배경에는 유리 효과의 투명도, 흐림, 어둡게 하기 설정이 함께 적용됩니다. 기본 상태의 탐색 아이콘은 글자 색상을 따르고, 누르거나 선택한 아이콘은 테마 강조 색상을 사용합니다.
- 다섯 개의 Feather 벡터 탐색 아이콘, 이름 툴팁, 하나의 움직이는 선택 표시를 제공합니다. Tab 키 탐색, Ctrl+1～5 페이지 전환, 화면 애니메이션 끄기를 지원합니다.
- 일시 정지, 미리 보기, 자막 숨기기, 마우스 클릭 통과, 대기 모드, 트레이 메뉴, 미리 보기 버전을 포함한 앱 내 공개 버전 업데이트 확인 기능이 있습니다. 설정 페이지는 마우스 휠과 터치패드 스크롤을 지원합니다.

이번 변경 및 수정 사항은 [0.1.12 릴리스 노트](https://github.com/occat666/occat-live-caption-download/releases/tag/v0.1.12)에서 확인할 수 있습니다.

## 0.1.10 업데이트

- 위상이 반대인 스테레오가 모노 변환 중 상쇄되는 문제와 다채널 입력의 중앙 채널에만 있는 음성이 지나치게 작아지는 문제를 수정했습니다. 지속되는 작은 음성의 시작 감지 기준을 낮추고 짧은 충격음과 배경 잡음에 대한 보호는 유지합니다.
- 입력 및 출력 장치 나열 오류를 따로 처리합니다. 기존 장치가 사라지면 이름과 소스 유형으로 복구하고, 후보가 모호하면 다시 선택하도록 안내하여 이름이 같은 마이크를 잘못 녹음하지 않습니다.
- 처리 중에는 가장 최근의 확정 및 임시 발화만 대기시키고 교체된 이전 오디오는 건너뛰어 재생을 따라갑니다. 전체 기록이 필요하면 실시간 속도를 따라갈 수 있는 모델을 선택하세요. 콘솔에서 장치 데이터 없음, 소리 수신, 인식 중을 구분합니다.
- 인식 신뢰도와 무음 확률을 함께 사용해 신뢰도가 낮은 반복·상투적인 문구를 걸러냅니다. 무음이나 배경 소리에서 잘못 생성되는 자막을 줄이면서 충분한 인식 근거가 있는 일반 발화는 유지합니다.
- 원문과 번역의 개별 스타일, 중일한 글리프, 5개 인터페이스 언어와 첫 사용 시 large-v3-turbo 다운로드를 유지합니다. 속도와 정확도는 모델, 내용과 하드웨어에 따라 달라지며 지연이나 환각이 전혀 없다고 보장하지 않습니다.

- 일반적인 중국어·영어 문맥 프롬프트를 제거하여 순음이 프롬프트 자체의 자막으로 생성되는 재현된 문제를 수정했습니다. 실제 모델 샘플로 수정 결과를 확인했습니다。

## 0.1.9 업데이트 (이전 릴리스)

- 인식 원문과 번역 자막의 글꼴, 크기, 굵기, 색상, 불투명도, 외곽선과 그림자를 각각 조정할 수 있습니다.
- 자막 모양에서 원문과 번역을 따로 설정하세요. 번역을 꺼도 번역 스타일을 미리 볼 수 있습니다. 위치, 배경, 줄 간격과 최대 줄 수는 공통입니다.
- 기존 설정은 번역 스타일의 초기값으로 한 번 복사되며, 이후에는 따로 저장됩니다. 5개 인터페이스 언어, 실시간 번역, 중일한 글리프와 첫 사용 시 large-v3-turbo 다운로드도 유지됩니다.


## 0.1.6 변경 사항 (이전 릴리스)

- 앱에서 미리 보기 버전을 포함한 최신 공개 버전을 확인하며 GitHub의 latest 정식 릴리스 API에만 의존하지 않습니다. 다운로드하고 확인하면 설치형은 현재 설치 폴더에 덮어써 업데이트하며 설정, 모델 및 언어 선택을 유지합니다.
- 무설치형은 업데이트 방법을 먼저 설명한 뒤 일반 설치 마법사를 엽니다. 기존 무설치 폴더를 조용히 덮어쓰지 않습니다. **0.1.5 이하 버전은 Releases에서 0.1.6 이상을 한 번 수동으로 설치해야 하며 이후에는 새 앱 내 업데이트를 사용할 수 있습니다.**
- 현재 자막의 번역이 끝난 뒤 자동 숨김 시간을 계산합니다. 중간 인식 결과 번역에는 호출 간격을 두고 현재 발화를 우선하여 너무 이른 숨김과 이전 번역이 새 문장을 덮는 문제를 줄입니다. 일시 정지, 전환, 지우기 및 이전 작업의 상태를 분리합니다.
- GitHub API 호출 제한이나 연결 장애가 발생하면 프로젝트의 공식 공개 업데이트 목록으로 확인을 이어갑니다. 설치 파일은 정확한 크기와 SHA-256으로 계속 검증합니다.

1. **Windows 10/11 x64**와 **14.44.35211 이상**의 Microsoft Visual C++ x64 런타임이 필요합니다. 런타임이 없거나 너무 오래된 경우, 설치 프로그램은 사용자 확인을 받은 뒤 Microsoft 공식 경로에서 다운로드하고 서명을 검증한 다음 런타임 설치 화면을 엽니다. 안내에 따라 Microsoft 라이선스와 관리자 권한 요청을 확인하면, 런타임 설치 후 자막 프로그램 설치가 자동으로 계속됩니다. 인터넷 연결이 필요하며 Windows를 자동으로 다시 시작하지 않습니다. Microsoft 설치 프로그램에서 다시 시작을 요구하면 작업을 저장하고 직접 다시 시작한 후 자막 설치 프로그램을 다시 실행하세요. 무설치형도 이 런타임을 먼저 갖추어야 합니다.
2. 설치형은 EXE를 두 번 클릭한 뒤 중국어 간체, 중국어 번체, 영어, 일본어, 한국어 중 하나를 선택하고 안내에 따라 설치하세요. 무설치형은 압축을 완전히 푼 후 실행해야 하며, EXE 파일만 따로 꺼내 실행하면 안 됩니다. 설치 프로그램에는 상용 코드 서명이 없으므로 다운로드 출처와 SHA-256을 확인하세요.
3. “猫猫本地实时字幕”를 실행하고 실제 소리를 재생하는 시스템 장치나 마이크를 선택하세요. 새 사용자의 기본 모델은 **Whisper large-v3-turbo**이며, 처음 사용할 때 인터넷에 연결하여 약 **1.6 GB**를 다운로드하고 파일을 검증해야 합니다. 이어받기와 다운로드 경로 전환을 지원합니다. 완성된 캐시는 로컬에서 우선 불러오며 오프라인으로 사용할 수 있습니다. 나머지 8개 인식 모델은 필요할 때 다운로드하거나 호환되는 로컬 모델을 가져오세요. 업데이트는 저장된 모델 선택을 덮어쓰지 않습니다.
4. 번역이 필요하면 “识别与翻译”(인식 및 번역)에서 호환되는 **M2M100** 모델을 다운로드하거나 가져온 다음 “实时翻译”(실시간 번역)를 켜세요. 원문만 보려면 꺼 둡니다.
5. “字幕外观”(자막 모양)에서 자막 스타일을, “窗口与待机”(창 및 대기)에서 위치, 마우스 클릭 통과, 대기 방식을 조절하세요. 하단 언어 메뉴는 简体中文, 繁體中文, English, 日本語, 한국어를 지원하며, 인식 언어는 별도로 설정합니다. 중국어·일본어·한국어 자막 글리프는 “字幕外观 → 识别原文 · 文字”(자막 모양 → 인식 원문 · 텍스트)에서 설정하며 화면 언어를 바꾸어도 함께 바뀌지 않습니다.

이번 소프트웨어 버전은 **0.1.12**, 릴리스 태그는 **`v0.1.12`**이며, 여전히 사전 공개 버전으로 제공합니다. **이번 버전은 앱에서 공개 미리 보기 업데이트를 지원합니다. 0.1.5 이하 버전은 기존 latest API만 조회하므로 0.1.6 이상을 한 번 수동으로 설치해야 합니다. 이후에는 앱에서 확인하고 업데이트할 수 있습니다.** 예전의 언어별 설치 프로그램을 사용 중이라면 위의 통합 설치 프로그램으로 수동 업데이트할 수 있습니다. 중국어 번체, 일본어, 한국어 설치 마법사에는 검토를 마친 구성 요소 약관의 영어 원문을 그대로 제공합니다.

사용자별로 설치하며 기존 설정을 우선 유지합니다. 설치형과 무설치형 모두 설정, 다운로드한 모델, 자막 기록을 `%LOCALAPPDATA%/OCCATLiveCaption`에 저장하며, 제거 후에도 사용자 데이터는 남습니다. 무설치형도 압축을 푼 폴더에 설정을 저장하지 않습니다.

**이전 버전에서 업데이트하는 경우:** 저장된 모델 선택과 다른 설정을 유지합니다. 업데이트 후에도 Base가 선택되어 있으면 인식 및 번역 → 인식 엔진 → 인식 모델에서 `large-v3-turbo`를 선택한 다음 ‘적용 후 모델 다시 로드’를 눌러 Turbo를 다운로드하고 사용하세요. 새 사용자의 기본 모델은 Turbo입니다.

## macOS 미리 보기 다운로드

**Apple Silicon과 Intel용 Mac 0.1.12 네이티브 미리 보기를 제공합니다.** 두 아키텍처 모두 클라우드 macOS 빌드, 동결 GUI 및 CPU 음성 인식 검사를 통과했으며 결과물을 로컬에서 독립 검증했습니다. 실제 Mac의 마이크와 시스템 오디오 캡처는 추가 확인이 필요합니다.

**macOS 14 이상이 필요합니다.** 프로세서에 맞는 DMG 하나를 선택하세요.

| Mac 종류 | 다운로드 |
| --- | --- |
| Apple Silicon (M1 이상) | [OCCATLiveCaption-0.1.12-macOS-arm64.dmg](https://github.com/occat666/occat-live-caption-download/releases/download/v0.1.12/OCCATLiveCaption-0.1.12-macOS-arm64.dmg) |
| Intel | [OCCATLiveCaption-0.1.12-macOS-x86_64.dmg](https://github.com/occat666/occat-live-caption-download/releases/download/v0.1.12/OCCATLiveCaption-0.1.12-macOS-x86_64.dmg) |

DMG를 열고 앱을 응용 프로그램 폴더로 드래그하세요. 이 미리 보기 패키지는 **ad-hoc 서명이며 Apple 공증을 받지 않았습니다**. 처음 실행을 시도한 뒤 시스템 설정 → 개인정보 보호 및 보안에서 해당 앱의 ‘확인 없이 열기’가 필요할 수 있습니다. 같은 Release의 [SHA256SUMS-macOS.txt](https://github.com/occat666/occat-live-caption-download/releases/download/v0.1.12/SHA256SUMS-macOS.txt)로 Mac 첨부 파일을 확인하세요. Mac의 업데이트 항목은 Releases 다운로드 페이지를 엽니다. 새 DMG를 받아 앱을 교체하며 설정, 모델, 자막 기록은 `~/Library/Application Support/OCCATLiveCaption`에 보관합니다.

Mac 버전은 **CPU 추론**을 사용합니다. 새 사용자는 여전히 처음 사용할 때 기본 모델인 **large-v3-turbo(약 1.6 GB)**를 다운로드합니다. 모델을 포함하거나 Base로 자동 변경하지 않으며 다른 모델은 필요할 때 다운로드합니다. 대형 모델의 CPU 처리 속도는 하드웨어에 따라 달라 실시간 성능을 보장하지 않습니다.

오디오는 CoreAudio 입력을 사용하며 캡처를 시작할 때 마이크 권한이 필요합니다. 재생 중인 시스템 소리를 받으려면 사용자가 직접 **BlackHole 등의 가상 입력을 설치하고 설정**해야 합니다. 앱은 오디오 드라이버를 포함하거나 설치하지 않습니다. [macOS 오디오 설정(중국어)](docs/macos-audio.md)을 참고하세요.

두 아키텍처의 네이티브 CI에서 동결 앱의 Cocoa 화면, 자막과 글꼴, 하위 프로세스 정리, HTTPS 인증서 검증을 확인했습니다. 실제 CPU 인식은 실행 중 `say`로 임시 생성한 음성과 `tiny.en`으로 검사했으며 Turbo의 성능이나 정확도를 측정한 것은 아닙니다. **실제 Mac의 마이크 권한과 녹음, BlackHole 시스템 오디오, 장시간 실행, Spaces와 전체 화면 앱 사이의 자막 최상위 표시 검증은 끝나지 않았습니다.** 구성 요소의 고지와 공유 라이브러리 교체 안내는 앱 안에 있으며 대응하는 제삼자 소스는 같은 Release의 첨부 자료를 확인하세요.

Mac 미리 보기에는 Source Han Sans, Source Han Serif 및 일본어·한국어 지역별 Source Han Sans 글꼴이 포함됩니다. 다른 글꼴은 로컬에서 가져올 수 있습니다.

## 검증 범위 및 사용 안내

Windows 0.1.12은 원문과 번역의 개별 스타일, 설정 이전, 인터페이스 언어와 자막 렌더링 회귀 검사, 동결 앱 검사, 5개 언어별 격리 설치·시작·제거, 공백을 포함한 사용자 지정 경로의 실제 0.1.11 → 0.1.12 덮어쓰기를 통과했습니다. 설정과 모델 검증 데이터가 보존되었으며 파일 버전은 **0.1.12.0**입니다. 번역 수명 주기 검사는 합성 번역을 사용하며 새로운 실제 M2M100 추론이 아닙니다. 깨끗한 Windows, 현장 오디오 또는 모든 하드웨어의 인수 검증을 의미하지 않습니다.

**런타임이 없는 깨끗한 Windows 환경에서는 아직 실제로 테스트하지 않았으며, 여전히 사전 공개 버전입니다.** 이러한 확인을 모든 GPU, 다중 모니터, 오디오 장치, 시스템 조합에 대한 보장으로 여기지는 않습니다.

인식과 번역은 사용자 컴퓨터에서 실행합니다. 첫 인식 모델 다운로드, 필요에 따른 번역 모델 다운로드 및 업데이트 확인에는 네트워크를 사용합니다. 모델 캐시가 완성되면 로컬에서 오프라인으로 사용할 수 있습니다. **자막 텍스트는 기본적으로 로컬에 저장합니다.** 고급 설정에서 저장을 끌 수 있으며, 꺼도 이전 기록은 삭제되지 않습니다. 개인 배경 이미지, 직접 가져온 모델과 글꼴은 공식 설치 패키지에 포함하지 않습니다.

자막과 번역에는 오류가 있을 수 있으므로 중요한 내용은 직접 확인하세요. 이 도구는 읽기를 돕기 위한 것으로, 전문적인 접근성 서비스나 공식 기록을 대신하지 않습니다. 사용 권한이 있는 내용만 처리하고, 다른 사람의 발언을 수집하기 전에 필요한 동의를 받으세요.
